Choosing the best spectral bands for hyperspectral images

Indian Pines scene, 10,249 labelled pixels, 200 bands, 16 land-cover classes. Everything below is produced by python demo.py.

The idea in three sentences. A hyperspectral camera records 200 colours per pixel, but many neighbouring colours say nearly the same thing. We pick a small set of bands that keeps almost all the useful information, so the hardware has less data to process. A good selection should give about the same land-cover accuracy as using all 200 bands.

1. The result

With 30 of 200 bands (15 %), the supervised method scores 83.9%, about the same as the 83.0% from all 200 bands (the best of 5 searches, picked using training pixels only). The best label-free method (Greedy R²) reaches 80.5%, which is 3.4 points lower; 8 of the 8 label-free methods fall below the supervised one, and the weakest (Entropy) gets 65.2%.

Supervised = the search is allowed to look at the class labels of the learning pixels. Unsupervised = it never sees labels, only the spectra.

6. How to explain the fairness

  • Same split for all: 20 % of pixels to learn from, 80 % kept hidden as the exam.
  • All methods pick bands using only the learning pixels. The exam pixels are used once, to grade.
  • Same classifier, same number of bands for every method.
  • Honest limits: one train/test split, nearby pixels can fall on both sides of the split, classifiers are not tuned, and the supervised search is one algorithm (GA) with 5 random starts. The full study (90 runs per setting, six algorithms) averages 83.1% at 30 bands, so treat differences of about one point as noise.
